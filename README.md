# 《小女生》六節課課程說明簡報

國小三年級國語文閱讀與寫作整合課程，將《小女生》課文重新安排為六節課，並加入：

- 概念象限：比較、辨異與說理
- 分類描述命名：整理課文描述卡，歸納外型、行為／特點、互動與情感
- 16 張可打亂、可顯示參考分類、可單張列印的抽取描述卡
- 生字詞語、篇章理解、分號與成語、靜態／動態描寫、短文寫作與評量

網站為單一 `index.html`，教材圖片均已嵌入，可離線使用，支援電腦、平板、手機、觸控滑動與鍵盤操作。
